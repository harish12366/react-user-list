# React User List

A responsive React application that fetches and displays user data from the JSONPlaceholder public API.

## Features

- Fetch user data using the Fetch API
- Manage data using React's `useState` hook
- Fetch data using the `useEffect` hook
- Display users dynamically using `map()`
- Reusable UserCard component using props
- Loading state while fetching data
- Error handling if the API request fails
- Responsive user card layout for desktop, tablet, and mobile

## Technologies Used

- React
- JavaScript
- JSX
- CSS
- Vite
- JSONPlaceholder API
